# EXP-004: deep-mode on the bugs dimension — 3 angle-diverse passes

- **Module:** review
- **Status:** draft
- **Failure pattern:** not a miss-pattern fix — this measures what the
  production `--deep` mode's angle-diverse recall actually buys over a single
  pass, on the stand, before recommending it. (User-requested check.)
- **Change (ONE thing):** the variant's `facets.json` runs the bugs dimension
  three times per trial — champion `bugs` plus `bugs-hostile-inputs` and
  `bugs-state-lifecycle` lens facets. `score.sh` pools all facet outputs of a
  trial into one findings set, so the per-trial UNION is what gets scored —
  the same union deep-mode ships.
- **Prediction:** recall_must +0..2 on real tasks; noise up, possibly
  double-counted (the judge does not dedup identical findings arriving from
  sibling facets — read the judge verdicts before trusting the noise number);
  cost ≈ +30% per arm.
- **Success gate:** Δrecall_must CI > 0 AND noise stays < 2× champion — else
  record "deep buys nothing at facet level" and stop.
- **Caveat (pre-registered):** a win may partly be a sampling effect (three
  draws instead of one). If it wins, run a control — three IDENTICAL bugs
  facets — before attributing the gain to angle diversity or promoting
  anything.
