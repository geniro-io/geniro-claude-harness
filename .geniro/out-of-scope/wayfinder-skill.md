# Wayfinder as a skill

A skill that charts an effort too big for one session as a map of decision tickets on the issue tracker, then resolves them one at a time.

## Why this is out of scope

`/geniro:plan` already grills a decision tree to an approved spec and breaks big work into milestones with `blocked_by` links. A separate skill is one more description loading every session and one more file to keep in step, for behavior that composes from the existing plan flow.
