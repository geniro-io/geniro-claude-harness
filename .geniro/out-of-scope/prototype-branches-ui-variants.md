# Prototype branches and UI variants

A skill that builds a throwaway prototype, either a state-model page or several UI variants, to answer a design question.

## Why this is out of scope

`/geniro:plan` with `--artifact` already puts a rendered plan, including a UI mockup layer, in front of the user before any code exists. A prototype skill is a second authoring surface for the same question.
