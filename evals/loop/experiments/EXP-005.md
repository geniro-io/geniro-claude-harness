# EXP-005: call-site contract chase as a REQUIRED output slot

- **Module:** review
- **Status:** rejected
- **Failure pattern:** the EXP-002/EXP-003 meta-lesson — prose directives
  don't survive busy diffs. EXP-002's transcript on real-4 shows the reviewer
  reading the "mandatory" chase sentence yet spending all attention on the
  diff's dominant feature; the throwing upload callee was never opened. A
  prose obligation is silently satisfiable at 50%; a required output table is
  not.
- **Change (ONE thing):** the chase directive in its structural form — the
  preamble adds a REQUIRED `## Callee contracts checked` output section: one
  line per call-site the diff adds or changes (`callee ← caller: contract —
  verdict`), filled before findings; every unhandled contract row must map to
  a finding.
- **Prediction:** unlocks real-4 gt-1 and/or real-5 gt-2/gt-4; retains the
  real-12 win. Risk: speculative "might throw" noise — planted-neg-1 rides
  in the mini-set as the noise sentinel; noise gate unchanged.
- **Success gate:** two-stage. Mini-screen (7 target-class tasks: real-4,
  real-5, real-12, real-13, real-14 + planted-2, planted-neg-1): any new must
  unlock with noise sane → full dev-19 screen; zero movement → rejected for
  ~$10. Full screen: Δrecall_must CI > 0, noise not significantly worse;
  holdout + 2nd family before promotion.

## Decision

REJECTED 2026-08-10 at the mini-screen gate: exact recall tie (all 6 must
tasks identical, every target miss unchanged), Δnoise +0.29 — for $9.15.

The autopsy is the valuable part. The mechanism EXECUTED: the table came back
thoroughly filled (real-4 bugs: 11 rows with genuine code citations), and it
contains the exact call-site of the target miss — `onFileUpload(file)` at the
gt-1 line — verdicted "handled". The reviewer read the callee's contract ONE
hop deep (return type `string | null`; the null path is handled) and never
followed the chain to the throwing `filesGetFileStatus` — the defect lives in
the rejection path, one call further down. Forced enumeration produces
looking, not transitive looking.

Third content experiment in a row (prose directive, checklist bullet,
structural slot) where the deterministic misses did not move, across two
executor families. Working conclusion: these misses are an executor
capability edge on busy diffs, not an instruction gap — further
reviewer-content tuning targets recall_must at sharply diminishing returns.
Remaining levers of a DIFFERENT mechanism: sampling (EXP-004 deep angles),
executor model, repo-rules injection (recall_all), transitive-chase (likely
cost/noise-prohibitive; don't attempt without a new idea for bounding it).
